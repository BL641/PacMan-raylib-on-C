# PacMan-raylib-on-C

Классический Pac-Man, написанный на чистом C с использованием библиотеки raylib.

# Описание
Реализация классической аркады Pac-Man. Игрок управляет жёлтым персонажем, 
собирает точки в лабиринте и избегает призраков.

# Технологии

- **Язык:** C
- **Библиотека:** raylib
- **Сборка:** Visual Studio
